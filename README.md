# 🎯 Зачем это нужно?

При подключении iPhone к Windows начинается настоящий квест:

> - файлы разбросаны по сотням папок (100APPLE, 101APPLE…); <br>
> - проводник тормозит; <br>
> - превью не показывает; <br>
> - iTunes только усложняет жизнь.

**iPhone Gallery Cleaner решает эти проблемы.**

| Проблема | Решение |
|----------|--------|
| 📂 Файлы разбросаны по папкам | Автоматически собирает все фото и видео |
| 🖼 Нет превью | Показывает миниатюры |
| 📏 Не видно размер | Сортировка по размеру |
| 📅 Сложно найти свежие | Сортировка по дате |
| 🔍 Нужный файл не найти | Поиск и фильтры |
| 📱 HEIC не открывается | Поддержка HEIC |

🚀 Подключил iPhone → открыл приложение → работаешь.

# 💡 Что такое AAE?

**AAE (Apple Adjustments and Effects)** — это XML-файлы редактирования iOS.

Они содержат информацию о:

- повороте  
- фильтрах  
- обрезке  

Оригинальный файл **не изменяется** — AAE содержит только инструкцию.

# ⚠ Решение проблем

### ❌ iPhone не найден

Проверьте:

- iPhone разблокирован  
- нажали **«Доверять этому компьютеру»**  
- кабель USB  
- установлен **iTunes или Apple Devices**  
- устройство видно в проводнике  

---

### ❌ HEIC файлы не открываются

```bash
pip install pillow-heif
```

---

### ❌ Видео без миниатюр

```bash
pip install opencv-python
```

---

### ❌ Очень медленное сканирование

Это нормально для MTP.

Скорость зависит от:

- количества файлов  
- USB кабеля  
- USB версии  
- производительности ПК  

10 000 файлов могут сканироваться несколько минут.
